# Third-Party Assets

The Nagashino sample uses the following runtime textures.

| Asset | Source | License |
| --- | --- | --- |
| Ground037 grass maps | https://ambientcg.com/view?id=Ground037 | CC0 1.0 |
| Ground085 mud maps | https://ambientcg.com/view?id=Ground085 | CC0 1.0 |
| Rock059 maps | https://ambientcg.com/view?id=Rock059 | CC0 1.0 |
| DaySkyHDRI057B sky panorama | https://ambientcg.com | CC0 1.0 |
| Island Tree 03 bark and leaf maps | https://polyhaven.com/a/island_tree_03 | CC0 1.0 |

The Island Tree 03 maps are used to generate lightweight, game-specific branch and leaf-card geometry in `tools/create_blockout.py`; the original high-poly model is not shipped with this sample.
